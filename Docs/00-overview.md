# Hệ thống Quản lý Thương mại Điện tử

## 1. Giới thiệu
Hệ thống Quản lý Thương mại Điện tử là một ứng dụng web được phát triển bằng ASP.NET Core MVC/API theo Layered Architecture.

Hệ thống hỗ trợ các chức năng duyệt sản phẩm, xử lý đơn hàng, quản lý thanh toán, theo dõi kho hàng và dịch vụ thông báo.

Hệ thống cho phép người dùng:
- Đăng ký / Đăng nhập
- Duyệt sản phẩm
- Thêm vào giỏ hàng
- Đặt hàng
- Thanh toán
- Theo dõi vận chuyển
- Viết đánh giá

Người dùng quản trị có thể:
- Quản lý sản phẩm
- Quản lý danh mục
- Quản lý kho hàng
- Tạo chương trình khuyến mãi
- Xử lý đơn hàng

---

## 2. Mục tiêu
- Cung cấp chức năng mua sắm trực tuyến
- Đảm bảo sự tách biệt rõ ràng giữa các chức năng
- Áp dụng Lập trình Hướng Đối tượng (OOP), Nguyên tắc SOLID và một số Design Pattern
- Duy trì kiến trúc có khả năng mở rộng và dễ bảo trì

---

## 3. Tech Stack
- Architecture: Layered Architecture
- Design Patterns: Repository Pattern, Dependency Injection (DI), Service Layer Pattern, Strategy Pattern, Factory Pattern, Observer Pattern, Unit Of Work
- Principle: SOLID, Clean Code
- Language: C#, LINQ
- BE: Asp.net core
- FE: Bootstrap, Template
- Database: SQL server
- ORM: Entity Framework Core
- Auth: Asp.net core identity
