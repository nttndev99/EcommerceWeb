# Ecommerce Management System

## 1. Introduction
Ecommerce Management System is a web application built using ASP.NET Core MVC following Layered Architecture.

The system supports product browsing, order processing, payment handling, inventory tracking, and notification services.

The system allows users to:
- Register / Login
- Browse products
- Add to cart
- Place orders
- Make payments
- Track shipping
- Leave reviews

Admin users can:
- Manage products
- Manage categories
- Manage inventory
- Create promotions
- Process orders

---

## 2. Objectives
- Provide online shopping functionality
- Ensure clean separation of concerns
- Apply OOP, SOLID, and Design Patterns
- Maintain scalable and maintainable architecture

---

## 3. Tech Stack
- Architecture: Clean Architecture
- Design Patterns: Repository Pattern, Dependency Injection (DI), Service Layer Pattern, Strategy Pattern, Factory Pattern, Observer Pattern, Unit Of Work
- Principle: SOLID, Clean Code
- Language: C#, LINQ
- BE: Asp.net core 
- Database: SQL server
- ORM: Entity Framework Core
- Auth: Asp.net core identity
